# Firewall-Based-Network-Security-simulations
Python simulation comparing stateless vs stateful firewalls on 1,000 labelled packets (SQLi, XSS, path traversal, brute force, blacklisted IPs). Stateful cuts false positives from 177 to 0 and lifts accuracy from 81.6% to 99.6%. Includes Matplotlib charts, Rich console output and an HTML/PDF report. Computer Networks mini project.
